# ⚡ Samico IoT & Smart Automation Control Center

Uma aplicação web moderna, responsiva e futurista para controle e monitoramento de dispositivos IoT e automação residencial/agrícola, desenvolvida pela **Samico / Agasti Smart Suite**.

## 🌟 Funcionalidades Principais

- **📊 Dashboard com Telemetria em Tempo Real**: Gráfico dinâmico em Canvas exibindo flutuações de consumo de energia (kW) e temperatura (°C).
- **💡 Controle de Iluminação Inteligente**: Ajuste de intensidade de brilho (0-100%) e acionamento de lâmpadas RGB/fitas LED.
- **❄️ Climatização & Termostato**: Dial customizado para controle de temperatura da casa e seleção de modos (*Frio*, *Calor*, *Ventilação*).
- **🛡️ Central de Segurança**: Visualização de câmera de monitoramento em tempo real (efeito scanline HD) e acionamento de fechadura biométrica.
- **🌱 Automação Agrícola (Agasti Agro)**: Leitura de sensores de umidade do solo e controle de iluminação UV para estufas.
- **💻 Terminal CLI & Streaming de Logs**: Terminal integrado para comandos de voz/texto (`status`, `lock`, `unlock`, `help`).

## 💻 Como Rodar Localmente

```bash
# Clone o repositório
git clone git@github.com:edielsonsamico/meu-primeiro-projeto.git

# Acesse a pasta do projeto
cd meu-primeiro-projeto

# Inicie um servidor local
python3 -m http.server 8080
```
Acesse no navegador em `http://localhost:8080`.
